# Hongli Liu — Academic homepage

[Visit the website](https://liuhongli775.github.io/)

A quiet, data-driven academic homepage for Hongli Liu, Research Assistant at The Hong Kong Polytechnic University. The page presents a coherent set of research questions across psycholinguistics, cognitive neuroscience, and computational modeling without using a CV-dashboard or product-landing-page structure.

## Page structure

The homepage contains six sections, in this order:

1. About Me
2. Research Interests
3. Research
4. Recent Reading
5. Hobbies
6. Message Me

Publications and the conference poster are incorporated into Research. There are intentionally no separate publications, computational-projects, education, resources, or contact sections.

## Where to edit content

| Content | Edit here |
| --- | --- |
| Name, position, research introduction, academic background, About links | `site.json` |
| Research Interests | `data/themes.json` |
| Research entries and methods | `data/projects.json` |
| Canonical publication/poster metadata | `site.json` |
| Recent Reading | `data/readings.json` |
| Hobbies, hobby photos, and message form copy | `site.json` |
| Page structure and rendering | `site.py` |
| Visual design | `assets/main.css` |
| Navigation state and message-form behavior | `assets/main.js` |

Do not edit `index.html` directly. It is generated by `site.py`.

For the two journal articles, `data/projects.json` stores the project framing and references the matching publication record in `site.json` through `publication_id`. This keeps titles, authors, journals, years, and DOIs in one canonical place. `publications.bib` is generated from `site.json`.

For Recent Reading, add objects with `title`, `authors`, `year`, `venue`, `url`, `note_label`, and `note` to `data/readings.json`. When the array is empty, the page renders only the modest line “Notes from recent reading will appear here.”

The optional `links.cv` and `links.scholar` values in `site.json` are blank, so those links are not rendered. Add verified public URLs only.

## Local build

```sh
python site.py
python test_english.py
python -m http.server 8000 --bind 127.0.0.1
```

The site has no framework, external fonts, analytics, trackers, or runtime dependencies. The builder and integrity tests use the Python standard library only.

When changing CSS, JavaScript, images, or `site.json`, update `asset_version` in `site.json` so visitors receive current assets after deployment.

## Publications and resources

Publications link to their DOI records. Publisher-formatted subscription PDFs are not hosted unless public distribution rights are verified. `publications.bib` contains the two journal-article citations.

The EEG/ERP Preprocessing Manual remains in `materials/` but is not rendered as a separate homepage section.

## Anonymous message form

The message form uses FormSubmit to forward one anonymous message field to `hongli.liu@polyu.edu.hk`. It requests no visitor name or email. FormSubmit processes submissions and requires one-time activation for the receiving address.

## Deployment

The generated static files are served from the repository root through GitHub Pages. The historical `/zh/index.html` address redirects to the English homepage and maps old anchors to the new page structure.
